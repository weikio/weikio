# Getting help with Weik.io

- Questions about building and running integrations go to [Discussions](https://github.com/weikio/weikio/discussions), where the Weik.io team and other users answer them.
- A bug goes in an issue with the [bug form](https://github.com/weikio/weikio/issues/new?template=bug.yml), and a problem in the docs with the [docs form](https://github.com/weikio/weikio/issues/new?template=docs.yml).
- A vulnerability goes to security@weik.io, as [SECURITY.md](SECURITY.md) describes.

Include the release that `weikio version` prints and, for a problem on the hub, the output of `weikio-backend doctor`.

## Support subscriptions

Support subscriptions cover the installations you run yourself, with questions, upgrade help and problem analysis answered by the team that develops Weik.io. Weik.io Dedicated includes support, and Weik.io Cloud includes it from the Startup plan up. The plans and their prices are on https://weik.io/support.
