# Security policy

## Reporting a vulnerability

Report a vulnerability in Weik.io to security@weik.io, or use GitHub's private vulnerability reporting on this repository under Security and Report a vulnerability. Don't describe it in a public issue or discussion before a fix is released.

A useful report has:

- the Weik.io release, which `weikio version` and the admin UI's version line show
- the steps that reproduce the problem
- what you saw and what you expected to see
- the requests, log lines or screenshots that show it, with secrets removed

The Weik.io team replies to each report and tells you which release carries the fix.

## Supported releases

| Release | Receives security fixes |
|---|---|
| 2026.2, the current release | Yes |
| 2026.1, the release before it | Yes |
| 2025.2 and earlier | No |

## How fixes are released

Fixes ship as patch releases, such as 2026.2.1, and the release notes of the fixing release describe each fix. Watch this repository's releases to hear about them, or read the notes at https://weik.io/releases.

How Weik.io protects your integrations and data is on https://weik.io/security.
