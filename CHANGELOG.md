# Changelog

The first Weik.io installation went into production in January 2018, four years before release 2022.1, and the team has published open source on GitHub since 2019. Each release has its notes on weik.io, with the files, the images and the upgrade command. The notes of 2026.2.0 say how 2026.2 is installed next to a 2026.1 installation or in its place.

| Release | Published | Highlights | Notes |
|---|---|---|---|
| 2026.2.1 | 28 October 2026 | Security headers and cookie handling on the gateway, agents that stop what they run after a day without Weik.io, and backend memory that stays level on Weik.io servers that run for weeks. | [Release notes](https://weik.io/releases/2026.2.1) |
| 2026.2.0 | 24 October 2026 | Camel integrations as versioned folders in Git, managed file transfer, API management, events, logs, metrics and traces, and installations on one server or on as many as you need. | [Release notes](https://weik.io/releases/2026.2.0) |
| 2026.1 | July 2026 | Running a route of an integration flow by hand from the UI, the CLI and the API, and the CLI as a native binary with install scripts. | [Release notes](https://weik.io/releases/2026.1) |
| 2025.2 | November 2025 | Event subscriptions and event channels with their own pages in the UI, variables with Dapr secrets, database change tracking and webhooks. | [Release notes](https://weik.io/releases/2025.2) |
| 2025.1 | January 2025 | More parameters for OpenID Connect authentication in API management. | [Release notes](https://weik.io/releases/2025.1) |
| 2024.3 | December 2024 | API management 1.0.0, projects for integration flows and file transfers, and the move to .NET 8. | [Release notes](https://weik.io/releases/2024.3) |
| 2024.2 | 2024 | A log viewer for file transfers, entity store search in the UI and the CLI, and a UI for WebJobs. | [Release notes](https://weik.io/releases/2024.2) |
| 2024.1 | 2024 | Arguments and filters for file transfers, faster entity store search and steadier WebJobs. | [Release notes](https://weik.io/releases/2024.1) |
| 2023.3 | 2023 | The first working version of managed file transfer, Azure Key Vault for its credentials and Apache Camel 4.0.0. | [Release notes](https://weik.io/releases/2023.3) |
| 2023.2 | 2023 | Further work on managed file transfer and the entity store, and agents that run flows. | [Release notes](https://weik.io/releases/2023.2) |
| 2023.1 | 2023 | WebJobs for background tasks, interactive notebooks, agents as Windows services and proxy agents. | [Release notes](https://weik.io/releases/2023.1) |
| 2022.1 | 2022 | The earliest release in these notes, with agents, integration flows and event-driven integrations. | [Release notes](https://weik.io/releases/2022.1) |

https://weik.io/company has the timeline, and what's coming is on https://weik.io/roadmap.
